# Roadmap

PushLens is intentionally a small local tool. The roadmap focuses on making the file list and the limits of each check easier to understand, while keeping the core usable without an account, network access, or extra runtime packages.

## Next areas to explore

- Show a clear preview of which `.gitignore` rules PushLens understands before creating an archive.
- Offer a portable Windows build for people who do not have Python installed.
- Add more language and project-specific hygiene checks without turning heuristic findings into security promises.
- Improve translations and accessibility in the desktop interface.

These are ideas, not release commitments. A focused issue with a concrete example is the best way to help prioritize them.
