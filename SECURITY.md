# Security policy

PushLens is a local-first publishing checklist. If private vulnerability reporting is enabled for this repository, use GitHub's **Report a vulnerability** feature rather than opening a public issue. Repository maintainers can enable the feature in the repository's security settings.

Do not include real credentials, personal information, private repositories, or unredacted reports in a security report. A tiny synthetic reproduction is preferred.

See [docs/SECURITY.md](docs/SECURITY.md) for what PushLens reads, writes, and cannot guarantee.
